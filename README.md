# Merge and Split

QGIS 文件合并和拆分插件。

## 1.0.0

当前第一阶段实现“合并”：

- 多选 QGIS 工程文件：qgz / qgs
- 多选单图层文件：OGR 支持的常见矢量格式
- 当前 QGIS 工程作为总文件
- 按图层名称匹配
- 将来源图层的要素追加到当前工程同名图层
- 来源和目标 CRS 不同时自动转换几何
- 保留当前工程原有图层及样式
- 目标工程不存在的图层默认跳过
- 不修改来源文件
- 暂不实现拆分

## 使用

1. 在 QGIS 中打开作为总文件的工程。
2. 启动 Merge and Split。
3. 点击“添加文件…”并多选工程或单图层文件。
4. 点击“开始合并”。
5. 工具按图层名称，将来源要素追加到当前工程同名图层。
6. 检查结果后保存当前 QGIS 工程。
