# Merge and Split

QGIS 文件合并和拆分插件。

## 当前阶段：合并

当前版本以“当前打开的 QGIS 工程”为工程1（总文件），不再依赖来源 QGZ/QGS 的数据源路径。

### 核心方式

1. 在 QGIS 中打开工程1。
2. 插件中一次添加多个数据文件夹。
3. 插件扫描每个文件夹中的实际矢量图层文件。
4. 以工程1的图层名称和顺序作为矩阵基准。
5. 同名称图层自动按行对齐。
6. 图层单元显示为 `图层名 [要素数量]`，例如 `DC [325]`；要素数量为 0 时显示灰色。
7. 文件夹列顶部的 `☑ / ☐` 控制整个文件夹是否参与合并。
8. 工程1没有的图层仍然留在它所属的文件夹列中，不单独集中到工程1下面。
9. 双击未匹配图层，可选择：
   - **新增图层**：在工程1创建同名新图层；
   - **移至已有图层**：指定工程1已有目标图层。
10. 对一个名称完成“新增/移至”后，所有文件夹中的同名称图层统一使用该映射。
11. CRS 不同时自动转换几何；来源文件不被修改。

### 当前支持的主要数据文件

- SHP
- GeoPackage（GPKG，多图层会尝试逐层读取）
- GeoJSON / JSON
- SQLite
- KML / KMZ
- GML / TAB（由 OGR/QGIS 实际支持情况决定）

## 使用

1. 在 QGIS 中打开作为工程1的工程。
2. 启动 **Merge and Split**。
3. 点击“添加文件夹…”并选择一个或多个数据文件夹。
4. 检查工程1与各文件夹的图层矩阵。
5. 文件夹列标题的 `☑ / ☐` 可控制整个文件夹。
6. 对工程1不存在的图层双击，选择“新增”或“移至”。
7. 点击“开始合并”。
8. 检查结果后保存工程1。
